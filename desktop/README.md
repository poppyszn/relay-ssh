# Relay desktop app

The Wails 3 app: a Go backend (this folder) and a Svelte 5 + xterm.js frontend (`frontend/`).
It shares its logic with the `relay-ssh` CLI through `../internal/core`; the root [README](../README.md)
explains what the app does, [CONTRIBUTING](../CONTRIBUTING.md) the checks to run.

```bash
RELAY_SSH_HOME=/tmp/relay-home wails3 dev -config ./build/config.yml -port 9245   # live reload, throwaway home
make desktop-check                                                            # from the repo root
```

## Layout

| Path | What lives there |
| --- | --- |
| `main.go`, `terminal.go`, `session.go` | App start-up, the loopback WebSocket, and one PTY per terminal pane. Bytes pass through untouched. |
| `profiles.go`, `folders.go`, `tools.go`, `keypass.go`, `snippets.go`, `files.go`, `forwards.go` | Wails services the UI calls: connections, tools (health, backup, import, keys), key passphrases, snippets, file browser, port forwards. |
| `rdp_service.go`, `rdp_gateway.go`, `rdp_codec.go`, `rdp_cert.go`, `rdp_tunnel.go` | Embedded RDP support: session management, loopback gateway speaking RDCleanPath, TOFU certificate store (`~/.config/relay-ssh/rdp_hosts.toml`), and jump tunnels. |
| `rdp-wasm/` | Rust wrapper crate building the WebAssembly IronRDP client loaded dynamically by the frontend. |
| `integration.go` | Shell integration for command blocks (local zsh/bash, and the remote opt-in snippet). |
| `vault_service.go`, `fill.go` | The password vault's service for the UI, and the rules that decide whether a password prompt may be answered. |
| `vault/` | The encrypted vault itself (age, scrypt): lifecycle, entries, file format, idle lock. No Wails, no sessions. |
| `frontend/src/components/` | Svelte components (and their tests). |
| `frontend/src/state/` | Shared reactive state: workspace (tabs and panes), settings, vault status, sidebar tree, search. |
| `frontend/src/lib/` | Plain TypeScript: terminal wrapper, pane tree, block tracking, themes, helpers, benchmark harness. |
| `frontend/bindings/` | Generated by Wails from the Go services; do not edit (regenerate with `wails3 generate bindings`). |
| `build/` | Wails packaging files for macOS, Windows and Linux, plus `config.yml` for `wails3 dev`. |
| `scripts/guardrails.sh` | Desktop-only invariants (no terminal emulation in Go, flow control, loopback socket). |

The Go services are in one `main` package because Wails binds them by type; anything that does
not need Wails or a session belongs in its own package (as `vault/` is). Only two bound Wails
methods may return a secret: `RevealSecret` (requires master password re-entry) and
`RdpService.Credentials` (one-shot password retrieval for active RDP session with intact vault
binding). All other methods return non-sensitive metadata only.
